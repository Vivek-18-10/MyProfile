# MyProfile – Personal Portfolio Website

A personal portfolio website built using HTML5 and CSS3 to showcase my introduction, skills, projects, and contact information.

## 🚀 Features

- **Home:** Personal introduction and profile image.
- **About Me:** Information about my background and interests.
- **Skills:** Displays technical and personal skills.
- **Projects:** Showcases my web development projects.
- **Contact:** Contact form with name, email, and message fields.
- **Navigation:** Simple navigation between website sections.
- **Responsive Design:** Clean and user-friendly layout.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
MyProfile/
│
├── index.html
├── style.css
└── README.md
```

## 💻 Installation & Usage

1. Clone this repository:

   ```bash
   git clone https://github.com/Vivek-18-10/MyProfile.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

This project was created to practice HTML and CSS, understand web development fundamentals, and improve front-end development skills.
